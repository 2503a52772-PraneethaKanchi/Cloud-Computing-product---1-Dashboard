End-to-End System Pipeline & Workflow

1

RFID Tag Tap

Student taps tag on RC522 reader connected to ESP32 SPI pins.

2

ESP32 Controller

Packages tag UID & gateway ID into JSON payload over TLS/WiFi.

3

AWS IoT Core

Receives message on MQTT topic classroom/gate/request.

4

AWS Lambda

Queries DynamoDB whitelist; decides ALLOWED/DENIED; writes access log.

5

DynamoDB + LED

Publishes status to ESP32: Green LED = Entry Allowed, Red LED = Denied.
